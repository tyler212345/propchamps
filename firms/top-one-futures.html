Key data points

Top One Futures runs four paths, all paying a flat 90% split. Elite Access is the cheap one-time 1-day-pass eval (no daily loss limit, 5-day payouts). Elite Daily is a monthly-subscription eval with daily payouts. Instant Sim Funded skips the evaluation entirely for a one-time fee (20% consistency, EOD-trailing drawdown). Ignite is a one-time instant-funding path (15% consistency, 10 copy-trade accounts). Code CHAMP applies the current discount at checkout; the site also rotates public promos. Runs on Tradovate, NinjaTrader, BlackArrow and WealthCharts (TradingView via Tradovate).
